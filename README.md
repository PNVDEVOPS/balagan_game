# үөр

## Описание

**«үөр»** — атмосферная нарративная игра о путнике, чья машина застряла зимой у трассы близь заброшенной якутской усадьбы начала XX века. Исследуя промёрзший дом при свете гаснущего фонаря и масляной лампы, он по запискам, вещам и загадкам восстанавливает историю угасшей семьи — и встречает то, что осталось в этих стенах. Каждое корридор в доме всё больше похож на ловушку, из которой есть лишь один выход.

## Жанр

**2D атмосферный нарративный хоррор-приключение** (сайд-скролл, исследование) с элементами головоломок и survival-horror (механика тьмы и света).

## Управление

| Действие                             | Клавиши                                                 |
| ------------------------------------ | ------------------------------------------------------- |
| Идти влево / вправо                  | `A` / `D` или `←` / `→`                                 |
| Бежать                               | `Shift` (удерживать)                                    |
| Взаимодействовать / осмотреть        | `E`                                                     |
| Спрятаться                           | `Q`                                                     |
| Инвентарь                            | `I` или `Tab`                                           |
| Пролистать реплику / закрыть записку | `Пробел` / `Enter` (также левый клик или любая клавиша) |
| Фонарь — рассеять тьму               | `F` (зажимать/часто нажимать в тёмных коридорах)        |
| Закрыть окно / головоломку / назад   | `Esc`                                                   |

**Мини-игра у камелька** (головоломка с дровами и шкатулкой): двигайте фигуры **мышью** — зажмите левую кнопку на фигуре и тяните по горизонтали или вертикали. Цель — вывести шкатулку на подсвеченную клетку.

**Ритуал у камелька** (поздняя часть игры): откройте инвентарь (`I`), кликом выберите дар, затем подойдите к камельку и взаимодействуйте — даров три, важен порядок.

## Как запустить

1. Распакуйте архив целиком в любую папку.
2. Запустите **`Балаган.exe`**.
3. Рядом с `.exe` должен лежать файл `Балаган.pck` — не разделяйте их.

Системные требования минимальны: Windows 10/11 (64-bit), видеокарта с поддержкой OpenGL/Vulkan. Установка не требуется.

---

## Прохождение (для жюри) — кратко

Демоверсия — вертикальный срез сюжета, ~10–15 минут:

1. **Трасса и лес** — машина застряла, путник идёт к дому; по пути собака-проводник и первые записки.
2. **Усадьба** — исследование комнат, чтение записок (журнал записок копится автоматически).
3. **Тёмные коридоры** — тьма наступает; в первом коридоре её отгоняют светом фонаря (`F`), дальше фонарь гаснет и нужна **масляная лампа** из прихожей.
4. **Главный зал и камелёк** — головоломка (мышью) открывает шкатулку с артефактом **харысхал**, после чего является дух — **Кыдаана**.
5. Демо завершается карточкой **«Конец демоверсии»**.

Прогресс автосохраняется; в меню есть «Продолжить» и счётчик найденных записок.

## Известные особенности и баги

- При самом первом запуске редактора/импорте в логах возможны предупреждения вида `invalid UID … using text path instead` — **косметические**, на игру не влияют (в собранном `.exe` не видны).
- Декор коридорах одинаковый (используется общая сцена) — сделано намеренно.
- Это **демоверсия**: после явления Кыдааны игра показывает «Конец демоверсии» и возвращает в меню (после концовки меню).
- Игра полностью на русском языке. Планируется добавление якутского
