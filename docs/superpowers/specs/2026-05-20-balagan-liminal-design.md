# Балаган — Лиминальная структура, Наайда, Субтитры Кыдааны
**Дата:** 2026-05-20
**Основан на:** `2026-05-20-balagan-refactor-design.md`

---

## 1. Концепция

Балаган — ловушка вне времени. Игрок заходит внутрь и не может выйти. Пространство петляет, повторяется, ощущается бесконечным. Кыдаана редко, но точечно говорит с игроком через субтитры на разных частях экрана. Наайда появляется как проводник перед каждой сюжетной головоломкой — всегда убегает, всегда недосягаема. В финале — впервые остаётся.

## 2. Полная карта комнат

### 2.1 Последовательность прохождения

```
[ЛЕСНАЯ ТРОПА] → Наайда впервые, ведёт в балаган
      ↓
[СЕНИ] ← повторяющаяся
      ↓
[ЧУЛАН] ← уникальный, лор, 1 посещение
      ↓
[СЕНИ] ← повтор (другой escape_attempts state)
      ↓
   ╔══[ЗАЛ]══╗  ← PUZZLE 1: Камелёк + Амулет
   ║          ║    → тёмный силуэт Кыдааны: плачет, исчезает
   ╚══════════╝
      ↓
[КОРИДОР] ← повторяющийся
      ↓
[СТОЛОВАЯ] ← уникальная, лор, 1 посещение
      ↓
╔══[СПАЛЬНЯ]══╗  ← PUZZLE 2: Колыбель + Кукла
╚═════════════╝
      ↓
[КОРИДОР] → [КОРИДОР] ← повторы
      ↓
[КЛАДОВАЯ] ← уникальная, лор, 1 посещение
      ↓
╔══[КОМНАТА КЫДААНЫ]══╗  ← PUZZLE 3: Зеркало + Серёжка
║  личные вещи          ║    Наайда у кровати, уходит сквозь стену
╚═══════════════════════╝
      ↓
[СЕНИ] → [СЕНИ] ← повторы
      ↓
   ╔══[ЗАЛ]══╗  ← возврат, Ритуал (1 попытка)
   ╚══════════╝
      ↓
   [ФИНАЛ]
```

### 2.2 Описание каждой комнаты

#### Повторяющиеся

**`room_entry.tscn` — Сени**
Тёмная прихожая. Развешанная одежда, скрипящий пол. Дверь «на выход» ведёт обратно в Зал — игрок понимает это не сразу. `escape_attempts` в GameManager управляет реакцией на попытки побега. Наайда появляется у двери в Зал при 2-м проходе (перед первой головоломкой).

**`room_corridor.tscn` — Коридор**
Длинный коридор с мерцающим светом в конце. Изредка (не чаще раза за прохождение) мелькает силуэт духа. Наайда появляется у дальней двери перед Спальней.

#### Уникальные (1 посещение каждая)

**`room_closet.tscn` — Чулан**
Охотничий инвентарь, сломанные капканы, ловушки. 2 записки отца (`note_father_1`, `note_father_2`). При первом посещении дверь открыта. При попытке пройти насквозь — выход заперт снаружи, видна только щель.

**`room_dining.tscn` — Столовая**
Стол с остатками еды, иконы в углу, замёрзшее окно. 1 записка матери (`note_mother_2`). Хомус лежит на подоконнике — интерактивный объект, при осмотре субтитр Кыдааны.

**`room_storage.tscn` — Кладовая**
Пустые мешки, сломанные горшки, перевёрнутая утварь. Ощущение полного исчезновения семьи. 1 записка окружения (`note_env_3`). Никаких механик — только атмосфера.

#### Нарративные

**`room_kydaana.tscn` — Комната Кыдааны**
Личные вещи Кыдааны: кровать с лоскутным одеялом, одежда на крючках, детские рисунки на стенах (включая рисунок из `note_env_5` — дом, собака, девочка). Зеркало на стене — **PUZZLE 3**. Наайда сидит у кровати при первом входе: при подходе игрока поворачивает голову, смотрит, медленно встаёт и уходит сквозь стену.

## 3. Механика петли (Escape Loop)

### 3.1 Переменная в GameManager
```gdscript
var escape_attempts: int = 0
```

### 3.2 Логика
Дверь «на выход» из Сеней (`door_exit`) ведёт обратно в Зал (`main_hall`). GameManager.change_room() как обычно — room_graph определяет путь.

| Попытка | Реакция |
|---|---|
| 1я | Тихий loop. Никакого текста. |
| 2я | Тихий loop. Никакого текста. |
| 3я | Loop + субтитр Кыдааны: *«Отсюда нет выхода.»* |
| 4я и далее | Тихий loop. |

### 3.3 room_graph изменения
Дверь `door_exit` в Сенях (`room_entry`) → `main_hall`.
Дверь `door_to_hall` в Сенях → `main_hall` (основной путь вперёд, та же цель но не считается побегом).

Различие: `door_exit` = попытка выйти наружу (инкрементирует `escape_attempts`). `door_to_hall` = движение вперёд по сюжету.

## 4. Первое появление Кыдааны (после Камелька)

После того как игрок подбирает Амулет и завершается флэшбэк:

1. Экран остаётся затемнённым
2. В дальнем углу Зала появляется `KydaanaSilhouette` — тёмная фигура, без лица, слегка размытая
3. Фигура стоит 3–4 секунды. Слышен тихий плач (AudioStreamPlayer, если аудио появится)
4. Произносит одну фразу субтитром: *(молчит — субтитра нет, только плач)*
5. Исчезает через fade-out 1.5 сек
6. После исчезновения — субтитр в правом верхнем углу: *«Ты видел меня.»*

**Реализация:** спрайт-заглушка `spirit_placeholder.png` с модуляцией `Color(0.05, 0.02, 0.1, 0.8)`. Тот же подход что у `SpiritGuardian` но без физики и AI — чисто визуальный узел, управляется кодом Зала.

## 5. Дуга Наайды

### 5.1 Все появления

| # | Где | Что происходит |
|---|---|---|
| 1 | `room_forest` | Появляется из-за деревьев. Смотрит на игрока. Бежит к балагану. Исчезает за дверью. Игрок думает — испуганная собака. |
| 2 | `room_entry` (перед Залом) | Стоит у двери в Зал, оборачивается на игрока, убегает внутрь. Видна только спиной. |
| 3 | `room_corridor` (перед Спальней) | Стоит у двери в Столовую. То же поведение — убегает. |
| 4 | `room_kydaana` | Сидит у кровати спиной. При подходе поворачивает голову, смотрит, встаёт, уходит сквозь стену. Впервые — не убегает сразу. |
| 5 | `room_finale` | Подходит к игроку. Впервые остаётся. Тычется носом в руку игрока. Смотрит на Кыдаану. Уходит вместе с ней в свет. |

### 5.2 Техническая реализация
- Появления 1–3: инстанцируется узел `Laika` (существующий `laika.tscn`) через логику комнаты, `auto_appear: false`, вызывается `appear()` по триггеру.
- Появление 4: специальная анимация в `room_kydaana_logic.gd` — `sit_at()` → при подходе игрока тween `modulate.a → 0`.
- Появление 5: существующая логика `finale.gd` расширяется — `laika.follow_player()` → `nose_touch_animation()` → fade вместе с Кыдааной.

### 5.3 Упоминания в записках

Добавить/изменить:
- `note_mother_1`: добавить строку *«Кыдаана целый день играла с Наайдой у реки — домой не загнать.»*
- `note_kydaana_4`: уже есть *«Наайда выла всю ночь»* — сохранить
- `note_kydaana_5`: уже есть *«Наайда не отходит»* — сохранить
- `note_env_5`: рисунок — уже описывает дом, собаку, девочку — сохранить

## 6. SubtitleManager — система субтитров Кыдааны

### 6.1 Архитектура
Новый автолоад `SubtitleManager` (`scripts/autoload/subtitle_manager.gd`).
`CanvasLayer` поверх всего (layer = 50, ниже pause menu).
Один активный субтитр в любой момент — очередь не накапливается.

```gdscript
func show_subtitle(text: String, screen_anchor: Vector2) -> void
```

### 6.2 Параметры отображения
- Fade-in: 0.8 сек
- Hang time: 3–5 сек (зависит от длины текста: `text.length() * 0.06` сек, min 3, max 5)
- Fade-out: 1.2 сек
- Шрифт: меньше диалогового, курсив, без рамки и фона
- Cooldown: минимум 90 сек между субтитрами

### 6.3 Позиции на экране (anchor нормализованные)
```
TOP_LEFT     = Vector2(0.1, 0.1)
TOP_CENTER   = Vector2(0.5, 0.08)
TOP_RIGHT    = Vector2(0.85, 0.1)
MID_LEFT     = Vector2(0.08, 0.5)
MID_RIGHT    = Vector2(0.82, 0.5)
BOTTOM_LEFT  = Vector2(0.1, 0.85)
BOTTOM_CENTER = Vector2(0.5, 0.88)
BOTTOM_RIGHT = Vector2(0.85, 0.85)
```

Существующая логика `_complete_ritual()` в `room_main_hall_logic.gd` остаётся. Изменения:
- Убрать диалоговые подсказки от Кыдааны во время ритуала
- Убрать сообщение «Выбери предмет в инвентаре (I), потом подойди к огню снова — в нужном порядке» после `RITUAL_READY` — заменить на просто: *«Пламя ждёт.»*

## 8. Изменения в room_graph.json

Новые комнаты добавляются в граф. Путь полностью пересматривается:

```json
"entry":    { "scene": "room_entry.tscn",    "doors": { "door_forward": "closet", "door_exit": "main_hall" } },
"closet":   { "scene": "room_closet.tscn",   "doors": { "door_forward": "entry2" } },
"entry2":   { "scene": "room_entry.tscn",    "doors": { "door_forward": "main_hall", "door_exit": "main_hall" } },
"main_hall": { ... "doors": { "door_bedroom": "corridor" } },
"corridor": { "scene": "room_corridor.tscn", "doors": { "door_forward": "dining" } },
"dining":   { "scene": "room_dining.tscn",   "doors": { "door_forward": "bedroom" } },
"bedroom":  { ... "doors": { "door_forward": "corridor2" } },
"corridor2":{ "scene": "room_corridor.tscn", "doors": { "door_forward": "corridor3" } },
"corridor3":{ "scene": "room_corridor.tscn", "doors": { "door_forward": "storage" } },
"storage":  { "scene": "room_storage.tscn",  "doors": { "door_forward": "kydaana_room" } },
"kydaana_room": { "scene": "room_kydaana.tscn", "doors": { "door_forward": "entry3" } },
"entry3":   { "scene": "room_entry.tscn",    "doors": { "door_forward": "entry4", "door_exit": "main_hall" } },
"entry4":   { "scene": "room_entry.tscn",    "doors": { "door_forward": "main_hall", "door_exit": "main_hall" } }
```

`room_basement.tscn` архивируется в `_legacy/` — его содержимое (зеркало-пазл) переезжает в `room_kydaana.tscn`.
