# Балаган — Game Design Spec

**Жанр:** 2D side-view horror-adventure (pixel art)
**Движок:** Godot 4.3+
**Разрешение:** 640x360 (масштаб 3x до 1920x1080)
**Язык:** GDScript
**MVP:** Демо 15–20 минут
**Спонсор:** Приют домашних животных

---

## Сюжет

Мужчина около 30 лет едет ночью по зимней трассе в Якутии. Во время сильной метели его машина ломается. Телефон не ловит, вокруг никого. Вдалеке — свет в лесу. На краю леса появляется якутская лайка, скулит и ведёт героя к старому балагану.

Внутри тепло, еда на столе, постель готова. Герой засыпает. Утром балаган пуст, дверь наружу заперта. Каждая попытка выйти возвращает обратно. Пространство искажается.

Лайка-проводник помогает ориентироваться. Герой собирает артефакты, раскрывает историю погибшей девушки Айыыны, чья душа заперта в балагане. Финальный ритуал освобождает Айыыну и разрушает проклятие.

**Твист:** лайка — тоже дух. Прощается с героем на пороге и растворяется.

## 2. Игрок и управление

**Движение:** влево/вправо, бег (Shift). Без прыжков.
**Взаимодействие:** E рядом с объектом. Подсказка «[E]» над интерактивными предметами.
**Укрытие:** Q рядом с укрытием.
**Инвентарь:** Tab/I.
**Фонарик:** всегда активен, заряжается E (остановка + анимация динамо).

**Структура ноды Player:**
```
CharacterBody2D
├── CollisionShape2D
├── AnimatedSprite2D (idle, walk, run, interact, crank)
├── PointLight2D (фонарик)
├── RayCast2D (луч взаимодействия)
└── Camera2D
```

**Анимации:**
- idle — 2-4 кадра
- walk — 4-6 кадров
- run — 4-6 кадров
- interact — 2-3 кадра
- crank — 4 кадра (кручение динамо)

Плейсхолдер: цветной прямоугольник 32x64 px.

## 3. Система комнат и искажение пространства

Каждая комната — отдельная `.tscn`. Переходы через двери загружают новую сцену.

**Граф комнат (`room_graph.json`):**
```json
{
  "rooms": {
    "entrance": {
      "scene": "res://scenes/rooms/room_entrance.tscn",
      "doors": {
        "door_inside": "main_hall"
      }
    },
    "main_hall": {
      "scene": "res://scenes/rooms/room_main_hall.tscn",
      "doors": {
        "door_entrance": "entrance",
        "door_left": "bedroom",
        "door_right": "corridor"
      }
    },
    "bedroom": {
      "scene": "res://scenes/rooms/room_bedroom.tscn",
      "doors": {
        "door_back": "main_hall"
      }
    },
    "corridor": {
      "scene": "res://scenes/rooms/room_corridor.tscn",
      "doors": {
        "door_left": "main_hall",
        "door_right": "storage",
        "door_down": "basement"
      }
    },
    "storage": {
      "scene": "res://scenes/rooms/room_storage.tscn",
      "doors": {
        "door_back": "corridor"
      }
    },
    "basement": {
      "scene": "res://scenes/rooms/room_basement.tscn",
      "doors": {
        "door_up": "corridor"
      }
    }
  }
}
```

**Искажение пространства:**
`GameManager` подменяет связи в графе. Триггеры:
- Сюжетные (нашёл артефакт → карта меняется)
- Временные (N переходов между комнатами)
- Скриптовые (конкретный момент истории)

**Переход между комнатами:**
1. Игрок подходит к двери → E
2. Затемнение (0.5 сек)
3. GameManager определяет следующую комнату по графу
4. Загрузка новой сцены, спавн у входной двери
5. Проявление (0.5 сек)

Хоррор-деталь: иногда при затемнении мелькает силуэт или раздаётся звук.

## 4. Инвентарь и интерактивные объекты

**Инвентарь:**
- Линейный список, 6-8 слотов (как DISTRAINT)
- Горизонтальная панель внизу экрана по Tab/I
- Предмет можно выбрать и применить на объект в комнате
- Артефакты (сюжетные, не расходуются) и расходники (ключ, батарейка)

**Типы интерактивных объектов:**

| Тип | Пример | Поведение |
|-----|--------|-----------|
| Pickable | Ключ, артефакт, записка | Подбирается в инвентарь |
| Examinable | Картина, зеркало, следы | Показывает текст |
| Usable | Дверь с замком, алтарь | Требует предмет из инвентаря |
| Door | Дверь между комнатами | Переход в другую комнату |
| Trigger | Невидимая зона | Запускает скрипт |
| Hideable | Шкаф, под столом, за печкой | Укрытие от духов (Q) |

**Базовый скрипт `interactable.gd`:**
Все объекты наследуют один скрипт с полями:
- `interaction_type` — тип
- `required_item` — нужный предмет (для Usable)
- `dialogue_text` — текст при осмотре
- `on_interact()` — действие

Головоломки собираются в редакторе без кода.

## 5. Духи и подача сюжета

### Лайка-проводник (дух)

- Появляется на краю экрана в начале, ведёт к балагану
- Полупрозрачный спрайт с мягким свечением, хвост виляет при приближении
- Подсказки без слов: садится у нужной двери, лает на опасность, скребёт лапой у предмета, рычит при угрозе
- Появляется и уходит — когда пропадает, тревога нарастает
- Бездействие 60 сек → лайка появляется и ведёт к точке прогресса
- При попытке погладить — рука проходит сквозь, лайка грустно смотрит

**Скрытые подсказки к твисту (незаметные при первом прохождении):**
- Не оставляет следов на снегу
- Исчезает в укрытии вместо того чтобы прятаться рядом
- Хранители её не замечают
- Записка упоминает «верного пса, не покинувшего хозяина после смерти»

### Айыына (неупокоенная душа)

- Цель спасения, не проводник
- Первая встреча: плачущий силуэт в конце коридора, убегает
- С каждым артефактом становится чётче: тень → контуры → полноценный призрак
- Не говорит с героем — история через записки, воспоминания, окружение
- Воспоминания: короткие флешбэки при находке артефактов (палитра → тёплые тона)

### Враждебные духи

**Хранители (патрульные):**
- Тёмные силуэты, медленный маршрут в комнате
- Зона обнаружения — конус (лёгкое тёмное марево)
- Попал в зону → 2 сек на реакцию: спрятаться или отступить
- Не ушёл → QTE с фонариком
- Привязаны к комнатам с артефактами

**Бродяга (скриптовый):**
- Не патрулирует, появляется в неожиданные моменты
- Шаги за спиной, тень на заднем плане, дыхание
- Иногда ложная тревога — звук без духа
- 2-3 раза за демо

### Поведение лайки при угрозе
- Рычит, прижимает уши → дух рядом
- Убегает к укрытию → подсказка куда прятаться
- Нет лайки в комнате → без предупреждения, максимум напряжения

### Environmental storytelling
- Записки на якутском с переводом героя
- Царапины на стенах, отметки пленников
- Предметы прежних жертв

## 6. Механика фонарика

### Обычный режим
- Заряд ~45 сек от полного до нуля
- E (зажать) → герой останавливается, анимация кручения динамо
- Каждое нажатие E = порция заряда
- Яркость луча = индикатор, без UI-бара
- Низкий заряд → мерцание, сужение луча

### QTE-режим (встреча с духом)
- Фонарик резко гаснет, дух приближается
- Быстрый мэшинг E, шкала заряда растёт
- Тряска экрана, звуковое давление
- Успел → вспышка, дух рассеивается
- Не успел → выброс в случайную комнату

### Скриптовое гашение (режиссура страха)
GameManager принудительно гасит фонарик. Динамо не работает — чистая беспомощность.

| Момент | Эффект |
|--------|--------|
| Первый вход в новую зону | Гаснет на 3 сек, шаги рядом, включается сам |
| Перед артефактом | Мерцает, динамо скрежещет но не заряжает |
| Флешбэк Айыыны | Гаснет, экран → тёплая палитра |
| Финальный ритуал | Гаснет, не включается — ритуал в темноте |
| Лайка предупреждает | Мигает дважды перед появлением духа |

Скриптовое гашение — 3-4 раза за демо. Редко, чтобы не обесценить.

## 7. Стелс и наказание

**Укрытия:**
- Объекты: шкаф, за печкой, под столом
- Q рядом с укрытием → экран сужается (эффект «выглядываю из щели»)
- Дух проходит мимо, лайка исчезает
- Фонарик разряжается и в укрытии

**Наказание при провале (без game over):**
- Дух касается героя → искажение экрана, шум, помехи
- Герой просыпается в случайной комнате
- Прогресс предметов сохранён, позиция потеряна
- Фонарик на минимуме — сразу крутить динамо

## 8. Головоломки и артефакты

### Артефакт 1 — Костяной амулет (tutorial)
- Комната: спальня
- Найти записку → прочитать подсказку → передвинуть предмет → амулет за ним
- Хранителя нет
- Воспоминание: Айыына входит в балаган живой

### Артефакт 2 — Бубен шамана (логика)
- Комната: кладовая → потайная комната
- Символы на стене + камни с символами → расставить по подсказке из другой комнаты
- 1 хранитель патрулирует
- Воспоминание: Айыына проводит ритуал, что-то идёт не так

### Артефакт 3 — Серьга Айыыны (стелс + QTE)
- Комната: подвал (самый тёмный, быстрый разряд)
- 3 фрагмента зеркала → собрать → зеркало показывает скрытый проход
- 2 хранителя, лайка отсутствует
- Воспоминание: полная картина трагедии

**Прогрессия сложности:**
```
Артефакт 1         Артефакт 2           Артефакт 3
Исследование    →  Логика + Стелс    →  Всё вместе + темнота
Нет врагов         1 хранитель          2 хранителя, нет лайки
Лёгкая записка     Записка из           Фрагменты по
                   другой комнаты       всей комнате
```

### Карта комнат (6 штук)
```
[Вход/Сени] ← старт, дверь заперта
     ↓
[Главный зал] ← хаб
   ↓         ↘
[Спальня]   [Коридор]
(арт.1)      ↓        ↘
          [Кладовая]  [Подвал]
          (арт.2)     (арт.3)
```

## 9. Звук и атмосфера

### Эмбиент (фоновые слои)
- Ветер и метель снаружи (глухой, через стены) — постоянно
- Скрип дерева балагана — случайные интервалы
- Тишина в некоторых комнатах — самый страшный звук

### Звуки игрока
- Шаги (разные для дерева/земли)
- Вжик-вжик динамо
- Вспышка фонарика
- Дыхание — учащается при угрозе и низком заряде

### Звуки духов
- Хранители: низкий гул, усиливается
- Бродяга: шаги за спиной, шёпот, скрежет
- Айыына: тихий плач, эхо через стены

### Лайка
- Скуление — зовёт за собой
- Рычание — опасность
- Радостный скулёж — артефакт близко

### Музыка
- Нет постоянной музыки, только эмбиент
- Стингеры: находка артефакта, флешбэк, появление бродяги
- Полноценная тема — только финальный ритуал

### Аудио-трюки
- Случайные звуки (10% шанс) при переходе между комнатами
- Звук за стеной, которого не должно быть
- Шёпот на грани слышимости при низком заряде

### Источники ассетов
- freesound.org (CC лицензия)
- sfxr/jsfxr (8-bit UI звуки)
- Эмбиент из бесплатных лупов

## 10. Финал и твист

### Финальная сцена

1. Ритуал завершён, злой дух изгнан
2. Айыына обретает покой — силуэт ярчает, улыбка, растворяется
3. Двери открываются. Герой идёт к выходу
4. Лайка сидит у двери, виляет хвостом
5. Идёт рядом с героем — **впервые** рядом, а не впереди
6. На пороге герой оборачивается — лайка села, не идёт дальше
7. Тянет руку — проходит сквозь
8. Лайка смотрит, медленно виляет хвостом
9. Тихий скулёж. Начинает светиться как Айыына
10. Растворяется. Последнее — виляющий хвост
11. Тишина. Герой один на пороге. Метель стихла.

### Пост-финал
- Возвращение к машине, заводится
- На заднем сиденье — костяной амулет
- Рядом — маленький клок шерсти
- Чёрный экран

### Титры
- «В память о верных друзьях, которые остаются рядом»
- Логотип приюта + «Они ждут тебя — [название приюта]»
